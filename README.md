# climada-dsge-cotedivoire
CLIMADA-DSGE-AIN-CGE: a structural Bayesian DSGE framework linking CLIMADA physical damages to macroeconomic transmission in Côte d'Ivoire. 5 blocks: households (90% non-Ricardian), climate productivity Ω_t, IS-NKPC-Taylor equilibrium, EVT/GPD tail analysis, and SLR adaptation NPV.
